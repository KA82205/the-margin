The Margin

How the three sites have been running

Read live from GitHub's public record of runs each time this page is opened. Each run is listed by what started it: GitHub's own schedule, the outside clock, a sister site, or a person. A check that finds nothing new is still a good check: it just saves nothing, so "last check" and "last time something new was saved" are different times.

GitHub allows a visitor about sixty readings an hour and this page makes about twelve. If the tables are empty, wait and reload.
